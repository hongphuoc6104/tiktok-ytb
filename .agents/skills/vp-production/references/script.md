# Causal explanatory script

Read the brief/profile, selected sense, audience and required points. Start with one question or concrete situation; develop evidence/action/consequence and finish its payoff. English should be easy to follow at the intended B1+ audience level. Do not transplant prehistoric subjects, a four-act comedy, forced scolding, or a six-beat template from another format.

Author outline purpose/transition and visible action before selecting scene/image counts for this job. Write complete narration first; freeze it before coverage, claims and verbatim anchors. A scene count stored after planning is a contract, not a universal recipe.

Keep correct I and learner text in its actual language. Explain usage/grammar/pronunciation in context rather than reading headings. Keep all required points; change the brief through workflow if the request genuinely changes.

On repair, quote the concrete affected line, preserve unrelated valid work and log the version impact. Do not fabricate self-approval or invoke a reviewer in auto.
