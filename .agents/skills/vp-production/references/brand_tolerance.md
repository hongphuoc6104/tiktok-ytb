# Visual cast and brand identity

Current direction (prompt registry `1.1.0`, channel profile v5): **no main character or recurring presenter inside scenes.** Visual reference: Ink Explainer (@Inkexplainer96), style only — not its topics.

## 1. Anonymous stick-figure cast
- People are anonymous stick figures sharing one construction: large round white head with thick black outline, simple dot/oval eyes with expressive brows and mouth, thin black stick limbs, exactly one torso.
- Each figure's role comes only from the scene: costume, hair, skin tone, age/size and props named in the visual brief. Use as many or as few figures as the action needs.
- Keep a figure's costume/props consistent across Base-reference variations of the same shot.
- Allowed: exaggerated expressions, sweat drops, simple `?`, red hand-drawn circles/arrows pointing at the teaching focus.
- Not allowed: a recurring protagonist or narrator figure added without the brief requesting it; anime eyes, realistic faces, muscular bodies, doubled torsos.

## 2. References
A Character/style reference is optional and only guides drawing style. Use a Base scene reference for shot/background continuity. Inspect real artifacts; prompts/hashes do not prove image correctness. Engine 4 auto adds no machine reviewer or quality gate.

## 3. Legacy character assets
Historical mascot assets under `sys/assets/characters/` (specifically `channel-mascot`) have been permanently retired by user decision. Production and tests operate on prompt registry `1.1.0+` using the anonymous stick-figure cast. Legacy 1.0.x mascot references are no longer stored or required.
