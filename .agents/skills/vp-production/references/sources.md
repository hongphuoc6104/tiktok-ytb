# Sources for production craft

Survey date: 24/09/2026. Internal instructions were adapted for Video Pilot; external repositories are not installed or executed. Saved source snapshots/commits are under `sys/reports/director-research-20260924/`.

- [calesthio/generative-media-skills](https://github.com/calesthio/generative-media-skills): educational-animation-production, social-short-production, storyboard-previsualization, cinematic-shot-direction, character-design-continuity, performance-direction, editing-montage, captions-media-accessibility, dialogue-editing-adr, sound-design-foley, audio-mixing-mastering. Used for craft decisions and separating evidence from heuristics; the surveyed MIT license is saved with the research.
- [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills): sw-scene-craft/sw-dialogue informed purposeful action/reaction/dialogue, adapted to short lessons rather than feature films.
- [BBC English in a Minute](https://downloads.bbc.co.uk/learningenglish/eiam/unit-1/190104_actually_vs_at_the_moment.pdf): concrete situations to distinguish meanings.
- [British Council Starting Out](https://learnenglish.britishcouncil.org/free-resources/general/video-series/starting-out): recurring characters/situations for A1–A2; not the current channel's default learner profile.
- [Mayer / Cambridge](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/principles-for-reducing-extraneous-processing-in-multimedia-learning-coherence-signaling-redundancy-spatial-contiguity-and-temporal-contiguity-principles/C98AB3A6CE760DD63C048936EA0B3B44): reduce extraneous detail and coordinate words/images; not a reason to prohibit useful foreign-language subtitles.
- [BBC R&D WHP295](https://downloads.bbc.co.uk/rd/pubs/whp/whp-pdf-files/WHP295.pdf): subtitle division follows language, not length alone.
- [Pixar in a Box](https://www.khanacademy.org/computing/pixar/storytelling): structure, character, visual language and feedback.
- [YouTube Shorts deep dive](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/): creator views on openings, not an algorithmic guarantee.

Canonical mascot, one sense, assigned tools, three data groups/five review outputs, preserved history and no paid API are project decisions, not rules imposed by these external sources.
