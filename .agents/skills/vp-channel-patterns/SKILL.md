# Channel Patterns

Use this skill when a user supplies a video or channel and asks for a detailed breakdown, comparable high-view examples, or a reusable method for making original work with related storytelling and editing logic.

Read [the analysis rubric](references/analysis-rubric.md) before collecting evidence. Read [the adaptation playbook](references/adaptation-playbook.md) when converting findings into reusable production guidance.

If the user asks to make and self-test an actual Video Pilot example, also read [the Video Pilot integration guide](references/video-pilot-integration.md) before authoring the job.

Resolve the exact channel from the supplied video and record its stable channel ID. Keep the target video separate from the comparison set. Select relevant comparison videos by the user's criterion; if the requested format has fewer than five useful examples, use the nearest same-channel formats and label the change. Capture the view-count date because public counts change.

For every claim, distinguish direct observation from inference. Separate narrative beats, visual shots, source image assets and storyboard samples. Never report a storyboard sample count as an image or cut count. Summarize dialogue in your own words unless a short quotation is essential. Only describe voice, music, effects and silence after listening to accessible audio; if audio or transcripts cannot be obtained, say so and continue with visual evidence.

Produce two usable outputs:

- A time-coded analysis of the target and a comparison table for selected channel videos, with sources, measurement method and confidence/limitations.
- A transferable playbook for a new subject: hook logic, narrative progression, visual functions, text/caption treatment, pacing ranges, audio questions to verify, and an original adaptation checklist.

Extract general techniques such as question-led hooks, visual contrasts, diagrams, timelines and payoff structure. Do not reproduce the reference script, exact scene sequence, jokes, characters, distinctive voice, soundtrack, marks or artwork. Change the subject, evidence, examples and scene solutions. Keep the project's existing creative profile and production boundaries intact; do not modify channel configuration or prompt templates as part of an analysis. If the user also asks to produce a video in Video Pilot, route that work through [vp-production](../vp-production/SKILL.md) under the appropriate production scope.
