# 735. look like — Chiếc bánh này trông giống thứ gì?

**Nghĩa/cách dùng trong bài:** trông giống như.

**Mục tiêu:** Nói sự giống nhau về hình dáng bằng look like cộng danh từ.

**Diễn tiến:** Nhìn hình bánh → so với mây → đổi góc → vẫn nhận ra hình mây.
