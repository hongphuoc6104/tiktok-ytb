# Sự cố nhóm 3

## Python hệ thống thiếu jsonschema

Lượt đọc adapter đầu tiên dừng trước khi gửi yêu cầu, báo `ModuleNotFoundError: No module named 'jsonschema'`.

Làm gì cho hết lỗi: dùng Python có sẵn tại `sys/.venv/bin/python`. Lượt tác giả sau đó đã bắt đầu trong môi trường này. Không cài gói, không sửa cấu hình hoặc mã được bảo vệ.
