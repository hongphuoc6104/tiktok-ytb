# so — Lỡ chuyến xe sáng

**Nghĩa chọn:** nên, vì vậy

**Chuyện:** Lỡ xe, Long rủ tôi đi bộ; khi mưa tới, tôi quyết định chờ dưới hiên để giữ bản chung và báo muộn, Long ở lại cùng.

## SC01

Xe buýt rời trạm, tôi vẫn đứng đợi. Long nhìn tôi: "The bus left, so we will walk." Xe đi rồi nên chúng ta sẽ đi bộ. Tôi cất vé, bước cạnh bạn.

**Chữ trên hình:** The bus left, so we will walk.
