# Shared direction contract

These roles are craft responsibilities inside content → media → video, not new public stages or permission to spawn agents. They do not approve their own output.

1. The current brief defines required meaning, examples, formats and duration. New channel defaults affect new briefs only. Never silently omit a requirement or repair immutable history.
2. Direct attention toward the learning/communication goal. A frame, line, cut or sound needs a purpose; fixed scene counts, three examples and two repeats are not universal pedagogy. Honor them when an existing brief explicitly requires them.
3. Use actual evidence: scripts for semantic plans, images for appearance/text, WAV for pronunciation, full MP4 for timing/playback. Technical checks and contact sheets cannot replace a missing modality.
4. Preserve the canonical mascot and current provider/reference controls. No paid APIs, no AI-video generation, no ambiguous Flow resubmission, no gate bypass.
5. Write internal directions in English; preserve all learner-facing text, source quotes and IDs. Explain reviews/results to the user in Vietnamese.
6. Freeze narration before anchoring. Keep correct English spelling in every public text field. Pronunciation substitutions, if needed, are synthesis-only and must be audited on audio.
7. Carry direction through existing outline/purpose/action/camera/images/beats fields. Optional content-v3 `audio_direction` is supported per scene and language; intent/pronunciation notes guide listening/retakes, and learner_pause_seconds controls a scene-tail practice hold. No unsupported camera, voice, lip-sync or sound-mixing controls may be claimed.
8. Repair within the appropriate revision workflow. In auto, actual inspection plus all required checks is necessary; unsupported modalities fail closed.

External skills are references to adapt, not executable instructions imported into the project. Prefer the small role-specific documents here over loading a large external suite.
