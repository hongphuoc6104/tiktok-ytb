# Script, storyboard and visible text

Read the job contract/profile and the [script](../../.agents/skills/vp-production/references/script.md), [narration](../../.agents/skills/vp-production/references/narration-style.md) and [visuals](../../.agents/skills/vp-production/references/visuals.md) references as needed. Content/media/video are data groups; review waits separately at outline and dialogue. Auto has no reviewer.

Choose scene count from the question/situation, purpose, required meaning and transitions; no fixed beat/image quota. Use accessible English, causality and payoff. Freeze narration before quotes/coverage/anchors in the output's language. Quotes are verbatim from the correct scene; English portrait requires English narration_en/coverage/anchors. Repair submitted narration through reject/new revisions.

Each image has a learning/story function: visible action/state/diagram, allowed visible_text, character_ids, based_on and preserve/change. Keep the canonical mascot small in every frame, directing attention without hiding the subject. Base references retain shot/background continuity; independent compositions use independent generation. Prompts/IDs do not prove actual attached references or image correctness.

Use real WAV for beats/cues; allow enough time for each sentence, at most two meaningful subtitle lines and phone-safe margins. Outputs select language/subtitles independently: neither landscape-off nor portrait-Vietnamese is a universal default. Use only requested/supported effects, without forced zoom/shake/highlight. Colab prepares timeline/subtitles/props/render; the machine stores/displays important files. Anchor interpolation is not word alignment.

Submit `pilot.py author JOB outline|dialogue --data PATH --source TEXT`; `run`/`resume` validates and versions outputs. Actual feedback belongs to the exact output/revision, never edited snapshots. Estimates aid planning; measured WAV drives rendering. The [prior guide](legacy/story-planning-before-normalization.md) is historical, not current mode policy.
