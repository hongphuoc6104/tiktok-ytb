# Contracts and data sources

Engine 4 manages authority, plans, ownership, five outputs and modes. `schemas/` defines payload/envelope formats. Each job's `workflow.json` stores version/mode/grant/management session. Outline/dialogue/audio/images/video have versioned snapshots and mode-appropriate decisions. Official tools write DB/events/history; never edit state directly.

The brief is the product contract: one bank sense, goals/required points, profile snapshot and independently selected language/aspect_ratio/subtitles/voice/speed in outputs. Narration/coverage/anchors use the required language. Scene count is selected through the saved outline, not six scenes or a four-act comedy default.

Remote audio/render retain account/session/request, input/reference/source hashes and output manifests. Real WAV determines timeline; interpolated segment cues are not word alignment. The image gallery uses real files without local contact-sheet composition. Technical registration does not prove brand similarity.

Auto executes without a reviewer; review waits at exactly the five main outputs. Content changes refresh dependent outputs while preserving unaffected WAV/images and request history. Separate write authority, schema/engine compatibility and immutable history. See [workflow](workflow.md), [permissions](../../AGENTS.md), and [saved v3 guide](legacy/contracts-before-normalization.md). Fixtures/manifests/hashes do not prove user viewing/listening or quality.
